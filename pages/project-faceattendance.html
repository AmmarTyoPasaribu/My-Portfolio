Absensi Lab 🎓

Sistem absensi laboratorium berbasis web menggunakan face recognition. Admin membuat sesi kelas dengan foto rombongan, dan sistem otomatis mendeteksi setiap wajah, mencocokkannya dengan roster mahasiswa terdaftar, lalu mencatat kehadiran — dengan review manual untuk wajah yang belum terkenali.

Live Demo Source Code

✨ Features

✦
Registrasi Mahasiswa — Upload foto mahasiswa, ekstrak embedding wajah, dan auto-enroll ke kelasnya
✦
Pembuatan Sesi — Upload foto kelas untuk deteksi multi-wajah otomatis dan pencocokan roster
✦
Review Manual — Ubah status kehadiran (hadir/absen/sakit) dan tautkan wajah belum dikenali ke mahasiswa
✦
Dashboard Absensi — Statistik real-time total mahasiswa, kelas, dan sesi
✦
Filter, Pencarian & Export — Filter sesi berdasarkan mata kuliah, kelas, atau tanggal, dan export kehadiran ke CSV
✦
Akses Berbasis Role — Sistem login dengan manajemen admin dan user

🛠 Tech Stack

FrontendNext.js, React, TypeScript, Tailwind CSS
BackendFastAPI (Python)
Face RecognitionMTCNN (detection) + InceptionResnetV1 / FaceNet (512-d embeddings), cosine similarity matching
DatabaseSupabase (PostgreSQL + pgvector)
MediaCloudinary
AuthJWT + bcrypt
